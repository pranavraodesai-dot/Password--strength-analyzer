# Password Strength Analyzer

A beginner-friendly web application that evaluates the strength of a password entered by the user.

## Features
- Checks password length, uppercase/lowercase letters, numbers and special characters.
- Identifies common words and repeated-character patterns.
- Displays Weak, Medium, Strong or Very Strong feedback.
- Gives suggestions to improve password security.
- Includes show/hide and clear password controls.
- Works on desktop and mobile screens.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`, or open it with Live Server in Visual Studio Code.
4. Enter a sample password and observe the strength feedback.

## Security Note
This is an educational demonstration. Password analysis runs in the browser; passwords are not stored or transmitted. Do not use this demo as a replacement for a production authentication or password-auditing system.

## Project Objective
To understand password security basics and learn how length, character variety and predictable patterns affect password strength.
